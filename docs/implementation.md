# DEV/OS: что реализовано

Спецификация в `docs/evolution/` описывает направление продукта. Этот файл
отделяет работающие возможности от интеграций, которым ещё нужен выбранный
внешний источник или оборудование.

| Область | Работает |
| --- | --- |
| Stagecraft | Семь экранов, реестр панелей, focus/zoom, поиск команд, справка, 12 визуалов, native/black background, auto-cycle, scope, intensity и числовые bindings |
| Композиции | Шесть пресетов, безопасный JSON-импорт, явное сохранение настроек, приоритет CLI, seed; импорт не запускает команды |
| Workspace | Два независимых tmux PTY, сохранение процессов при смене экранов, фокус, resize, ограниченный ввод и замедление скрытых capture |
| Site/Body | JSON snapshot, JSONL/FIFO, HTTP polling, TTL/backoff, единицы и окна, LIVE без подмены demo; BPM и RR различаются |
| Atlas | Пример протокола Ekza для аватаров и ассетов; отдельно настоящее read-only дерево/status Git |
| Checks | Явные argv, реальный exit code/revision, ограниченный stdout/stderr, timeout/cancel и просмотр результата |
| Replay | JSONL/gzip, rotation, checkpoints, seed/начальные параметры, seek и поиск ошибки; восстановление событий не запускает jobs |
| Privacy | Stream View скрывает личные панели; запись по умолчанию исключает пульс, терминальный текст и полные prompts |
| Arena | Demo, Watch, ручной редактируемый Relay и конечный Mission; отдельные session ID, рабочие папки, лимиты, cancellation и no-progress |
| Artifacts | Реальные патчи/хеши, инспектор публичных результатов и независимых проверок; отдельный кандидат Split с конфликтными артефактами |

## Что нужно подключить отдельно

- D04: конкретный сайт/аналитика. Универсальный HTTP/JSON-вход работает;
  доступ к аккаунту аналитики и проверка чисел сайта не настраивались.
- D06: конкретный датчик/телефон. JSON BPM/RR bridge работает; BLE-драйвер и
  сверка с физическим устройством требуют выбранного оборудования.
- CLI auth и доступ к моделям настраивает пользователь в своих установленных
  инструментах. Проверки этой итерации используют fake JSONL-процессы и не
  расходуют модельные запросы.
- Встроенных SDK approval bridge, жёсткого денежного лимита и восстановления
  managed coordinator после перезапуска нет. CLI capabilities проверяются
  перед явной миссией. Неизвестная стоимость остаётся unknown.
- Split создаёт исходный кандидат; конфликты и его проверки видны человеку.
  Автоматического слияния, deployment и переноса в основной checkout нет.
- Replay восстанавливает нормализованные события и начальную композицию,
  а не видеозапись терминала, полную историю ручных UI-действий или живые
  model sessions. Для нового запуска модели replay не используется.

## Проверка

`python3 -m unittest discover -s tests` проверяет pure rendering, числовые
контракты и старение данных, настоящие локальные HTTP/FIFO/file источники,
реальные PTY и команды, fake managed CLI, отдельные workspace, конфликты,
клавиатурный фокус и восстановление curses после выхода.

Снимки Visual Lab и Arena в `docs/screenshots/` получены текущим Renderer из
bundled-исходников и явно синтетических данных. Чистый рендер семи экранов
проверен при 144×44 и 240×60: максимум 3,67/5,56 мс на текущем Mac. Эти значения
не включают terminal I/O и не являются обещанием FPS для любого терминала.
